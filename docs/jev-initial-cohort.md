# Prospective Jev initial-decision cohort

The [article](https://huggingface.co/blog/ntc-ai/particle-sliders-learn-the-behavior-keep-the-quest) selects complete answers under a shared behavior criterion and trains the state before the initial answer. The original agent extension instead selects fresh-test wins over a failed OFF and includes later assistant decisions. At declaration it had supplied zero targets. The separate [Jev protocol](../research/jev-evidence-loop-v1.json) was frozen before any real trajectory received its behavior grade; its status field records that preregistration snapshot.

Each selected teacher must finish cleanly, have complete captured requests/completions and pass fresh repository verification. Its normalized Jev score must be at least .75 and strictly higher than the matched, clean, fully captured OFF episode. A passing OFF is eligible for this behavior comparison. All four declared arms need terminal records; unsuccessful or incomplete other teachers remain recorded and supply no targets. Existing binary cohorts keep their original rules and receipts.

The fixed five-level Score measures observed causal repair evidence: investigation, a relevant change and a checking experiment, with the highest level requiring observed before/after reproduction and relevant regression checks. The API receives the sanitized TRAIN issue, actual captured terminal history and completion. System/developer messages, arm labels and verifier results are excluded from judge state. Retained compaction summaries remain visible; discarded events receive no invented credit. Reference/test patches, DEV and holdout feedback never enter the judge.

One complete initial ordinary assistant request supplies each qualified task's paired context, before any prior assistant/tool history. Student and teacher receive the same full question, tools, generation controls and empty conversation history; the teacher additionally receives the declared successful behavioral cue. This follows the article's training boundary and remains distinct from the existing all-decision/full-history extension. It preserves the full hidden vector, public PG recipes and the declared training batch/horizon. It does not crop a later request or replace hidden-state training with answer imitation.

The [real synthetic rubric control](../reports/jev-evidence-loop-rubric-control-v1.json) passes through NanoGPT's requested `typesafe/jev-latest` alias: no attempt .195, unsupported claim .2975, observed closed loop .9925 on the declared zero-to-one scale. These three controls establish ordering for those synthetic examples, not real-domain judgment accuracy. Raw scores, probabilities, confidence and response identities remain recorded. Confidence is not an extra admission threshold. The initial draft's budget label was corrected and initial-boundary metadata completed; the rubric and actual API request bytes are unchanged, with no additional paid call for replay.

There is one grading pass per eligible arm, no automatic model fallback, no paid retry to seek a better score, and no truncation after an over-limit response. Missing, declined or invalid judgments remain unqualified. NanoGPT names the latest alias rather than an authenticated underlying checkpoint; that limitation remains explicit.

The operational budget remains `official-default-60m-v1`: 60 minutes, 100 declared tool calls, 500 turns and 300-second commands, with `tools-v2` and `official-compaction-v2` unchanged. Actual tool counts and controller failures remain in receipts. Reserved conversion tasks `fastapi_13207` and `fastapi_13537` cannot enter fitting. The protocol loader rejects budget drift, failed-teacher admission and later-history targets.

The failed infrastructure quartet exercises this path with zero eligible grades, zero API calls and zero targets.

Failures remain in the run; incomplete collections or grading passes require explicit reconciliation.

They do not establish real-domain judge accuracy. Earlier binary cohorts retain their original rules and outcomes. Selection remains actual DEV repository-test resolution, followed by the locked holdout and a learned official Kaggle score above contemporaneous SOTA; a higher Jev score cannot satisfy that goal.
