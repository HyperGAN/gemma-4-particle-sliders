# Official history compaction

The authenticated harness README and the Kaggle staff [starter notebook](https://www.kaggle.com/code/ryanholbrook/getting-started-gemma-4-developer-agent) configure ADK event compaction at 14,336 prompt tokens, keeping five recent events, with a 15-invocation sliding interval and overlap of two. They also configure context caching with a 2,048-token minimum, 1,800-second TTL and interval of ten.

Earlier local runs constructed `EvalConfig` with neither option. The installed `swegemma` runner passes those options to `App` only when provided. The old trajectories remain valid matched research attempts under their explicit budgets, but they do not establish parity with the official history-management setup. Their failures, tests, context-exhaustion proofs and zero-target outcomes retain their original identities. No old result is promoted to a compacted run.

New direct trajectory commands default to `official-compaction-v1`. Collection plans declare their history profile and settings explicitly; legacy plans use `uncompacted-v1`. Each collector passes that choice explicitly to the agent runner, and all four arms must match it. The contract, captured outcome and verifier receipt bind the profile. All live old collectors retain their frozen checkout.

The host uses public `ContextCacheConfig`, `EventsCompactionConfig` and `LlmEventSummarizer` APIs with the starter's values and the same registered model. The summarizer's prompt and behavior are unchanged. A scoped context variable marks summary transport calls in the request journal. They remain fully recorded and hash-bound but cannot become assistant-decision training targets. A summary tag cannot hide an ordinary system/tool decision. Subsequent assistant targets retain exactly the history actually observed, including any compacted summary; teacher/student differ only by the declared behavioral system instruction.

Curation controls retain decision indices across auxiliary calls, reject mixed profiles and preserve complete matched observed history.
