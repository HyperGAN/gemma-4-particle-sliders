# Experiment protocol v1

The goal remains to exceed the competition's best verified score with an example that uses current ParticleGAN/Particle Sliders. No engineering milestone substitutes for that result.

1. Verify current Kaggle entry, allowed model variants, official harness version, submission format and leaderboard. Preserve a timestamped source snapshot. The accessible mirror is a preparation input, not current authority.
2. Qualify the CPU path: native architecture and parameter ownership; exact strength-zero bypass; live adversarial gradients; full disk continuation; native inference export; approximation metrics and PEFT loading; compiler acceptance; real-task scorer controls. A reference-patch positive control is verifier calibration, never an agent result.
3. Run a prompt-only baseline and the three declared target instructions on TRAIN tasks through the official sandbox. Hold task IDs, model, quantization, seed, sampling and budgets fixed. Keep errors and timeouts in the denominator. Store complete trajectories and fresh-container test receipts privately as run artifacts. A trajectory-to-canonical-message adapter and native-agent serving parity still need real-run qualification.
4. Curate successful contexts where the positive run resolves the task and the OFF run does not. Fixed tie break: fewer tool calls, then lower elapsed time, then instruction name. The judge is executable validation, not a generated ideal patch. Only TRAIN contexts enter the cache. Teacher/student histories match exactly except for the behavioral system instruction.
5. Pin model/tokenizer revisions and cache full native final hidden states at assistant decision boundaries. Do not truncate wide states or reinterpret them as categorical. Cache identity binds token bytes, model revision, training manifest and selected contexts.
6. Run RHBI and EMPF as separate fresh 0.10 cohorts. Seed 0, same initialization, rows and declared update horizon. Preserve each resolved recipe, source hash, optimizer profile, complete RNG state and raw weights. First measure actual memory and step time with a bounded shared-GPU chunk. No seed-only search. A larger rate/budget search requires a recorded hypothesis and tuning budget.
7. Evaluate native and distilled behavior separately. Linear conversion fits only TRAIN activations and uses disjoint TRAIN task IDs for approximation probes. It keeps the native up matrices and records strength, ridge, per-layer errors and source/checkpoint identity. An approximation score does not establish task accuracy. Production vLLM must load the exported LoRA and demonstrate an actual effect at the intended strength.
8. Select on DEV task resolution, error rate and budget; retain the OFF and prompt-only controls. Confirm the locked choice once on the untouched repository-level holdout. Report task-paired wins/losses, uncertainty and repository dependence. The initial DEV has only 13 Requests tasks; its uncertainty and domain limitation must remain visible.
9. Package the selected PEFT candidate with the same agent config, validate/compile it using the current harness, run end-to-end production-format evaluation, and submit through the entered Kaggle account. Record submission ID, archive hash, official status/score and contemporaneous leading score. Respect the competition's submission limits. Iterate on new TRAIN/DEV hypotheses without tuning to the confirmation holdout or hidden tests.

Reference solution and validation patches are available only to verifier controls. They must not be passed into model prompts, training targets, calibration contexts, or a serving agent. The visible task writer uses an explicit field allowlist. Curation JSON can check receipt consistency but cannot authenticate an invented external receipt; the verifier integration must produce those receipts from actual executions.

The current artifact uses the core's paired-error game: the critic compares noise with the same noise shifted by student minus target hidden state, conditioned on the frozen neutral state. Public ParticleGAN factories own adversarial losses, critic penalties, prior regularization, optimizer updates and schedules. The host owns model forwards, matched contexts and sampling streams. Domain forwarding and CUDA execution changes are explicit source-bound host adaptations.

Authenticated Kaggle access and current harness installation are verified. Real-task controls and CPU request capture pass; pretrained native tool calling and shared-GPU cost are now measured. Eager attention exceeded the memory cap, so a separate SDPA cohort uses the same weights and cap with explicit backend identity. Its first OFF task timed out without a patch. Verified schema v3 preserves that failed timeout and its actual first-request bytes despite a canceled final model call; a successful teacher still needs complete capture. This admission correction was declared before any positive result. Remaining work includes complete TRAIN curation, trained Gemma behavior, quantized parity/evaluation, DEV selection, holdout confirmation, and official leaderboard superiority.
